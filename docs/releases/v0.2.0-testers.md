# Chatalume 0.2 — tester handoff

Unpublished candidate prepared for GitHub distribution. No website or store release is authorized by this file. The owner must approve publication of the exact ZIP. Signed-in provider layouts and the reported Gemini account/avatar issue remain manual acceptance items.

## Install and update

1. Download `chatalume-v0.2.0.zip` and its matching `.zip.sha256` from the maintainer's GitHub release when published.
2. Extract the ZIP to a permanent folder. The selected folder must contain `manifest.json`, not another ZIP or the repository source.
3. Open `chrome://extensions` or `brave://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted folder.
4. Open Chatalume from the Extensions menu. Choose Mist, Dusk, Paper or your own image. Refresh an already-open supported chat.
5. For updates, keep the same loaded folder and extension entry, replace its files with the new build, then choose **Reload** and refresh chats. Do not remove the old entry or move the loaded folder if retaining local preferences matters. ZIP installs do not update automatically.

The browser reports broad-looking access to three chat sites because Chatalume changes their appearance. Images/preferences stay in local extension storage; a displayed image is readable by scripts on the supported site. No new permissions, analytics, account or image-upload service were added.

## Everyday use

- Wallpaper switch: pause only the current provider.
- Three-dot menu / toolbar: reading comfort and **Edit wallpaper**. Toolbar also offers **Pause everywhere**.
- Editor: choose the wallpaper; use **Apply settings to** to choose global defaults or a provider. Fine-tuning is optional and collapsed by default.
- **Use global settings** clears the selected provider's overrides. **Reset effects** changes only appearance values. **Remove wallpaper** deletes the saved upload and preset selection.
- New installs show wallpapers at 100% visibility. Existing saved opacity is retained. Reading comfort softens conversation text only, without covering the whole page or adding surfaces to native controls.

## Report feedback

Use the repository's provider-bug template. Include extension/browser version, provider, theme, new chat or conversation, and a short reproduction. Prefer synthetic text and redacted screenshots. Never attach real conversations, session state, cookies, credentials, or a full settings export. Mention whether you kept using Chatalume after a few days and which control was confusing.

## Recovery

Pause everywhere or disable Chatalume to restore native appearance. Disabling preserves preferences. Removing the extension removes its local storage. Keep a copy of the current ZIP and checksum; use a maintainer-provided higher-version repair rather than manually downgrading stored settings.
