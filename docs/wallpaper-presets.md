# Bundled wallpaper presets

Mist, Dusk, and Paper are original SVG illustrations created for this repository without third-party images. They are licensed under the repository's [MIT license](../LICENSE).

| Stable ID | Asset | Appearance |
| --- | --- | --- |
| `mist` | `public/wallpapers/mist.svg` | Soft fog and layered hills |
| `dusk` | `public/wallpapers/dusk.svg` | Moonlit mountain silhouettes |
| `paper` | `public/wallpapers/paper.svg` | Warm folded-paper geometry |

Each asset is 1600 × 900, self-contained, and has no script or remote resource references. Keep stable IDs and paths across upgrades. Preset selection retains the saved custom upload; Remove wallpaper clears both sources.
