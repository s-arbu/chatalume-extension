Before you settle in

Which browsers and AI services does it support?

The extension targets Chromium browsers and has adapters for ChatGPT, Claude and Gemini. Chrome and Brave are the intended initial release browsers; final manual compatibility checks are pending.

Can I install it in one click?

Not from this beta ZIP. It uses the Developer Mode / Load unpacked workflow above. A normal Chrome Web Store install link will be added only after an approved listing exists.

Can I pause it without losing my image?

Yes. Pause the current provider with the on-page switch, or choose Pause everywhere in the toolbar. Reset effects keeps your image; Remove wallpaper deletes the saved source.

What about animated wallpapers and reduced motion?

GIFs use a still frame when the system requests reduced motion. You can explicitly allow animation in General settings. Original GIF bytes remain saved, and paused previews stop moving.

How do I update the unpacked beta?

Keep the same extension entry and loaded folder. Replace its built files with the new build, then use Reload in the extension manager and refresh chat tabs. A new folder or store identity may create separate storage, so keep the original installation until your settings are accounted for.
